专题图模块说明
================================================================================

模块名称： 专题图生成模块
负  责 人： 贾思雨
文  件 名： mapper.py
功能描述： 将变化检测或地物分类的结果（.udbx 格式）自动生成包含
           图例、比例尺、指北针和边框的专题图图片（PNG 格式）


一、对外函数
================================================================================

函数名称： generate_thematic_map

函数功能： 打开数据源，读取指定矢量数据集，渲染地图并输出带图例、
           比例尺、指北针和边框的专题图图片。

是否耗时： 是（取决于数据量大小）

UI线程：   是，建议放入 QThread / 工作线程中执行

函数签名：
--------------------------------------------------------------------------------
def generate_thematic_map(
    udbx_path: str,
    dataset_name: str,
    output_image: str,
    theme_field: str = "类别编码",
    width: int = 1200,
    height: int = 900
) -> bool
--------------------------------------------------------------------------------


二、参数说明
================================================================================

参数名称        类型    必填    默认值    说明
--------------------------------------------------------------------------------
udbx_path        str     是      无        UDBX 数据源文件路径
dataset_name    str     是      无        要渲染的矢量数据集名称
output_image    str     是      无        输出的 PNG 图片路径
theme_field     str     否      "类别编码" 专题图分类字段名
width           int     否      1200      输出图片宽度（像素）
height          int     否      900       输出图片高度（像素）


三、返回值
================================================================================

类型： bool

True   - 专题图生成成功
False  - 专题图生成失败（原因会打印到控制台）


四、调用示例
================================================================================

示例1：基本调用
--------------------------------------------------------------------------------
from mapper import generate_thematic_map

ok = generate_thematic_map(
    udbx_path=r"D:/项目根目录/classification/classify_result.udbx",
    dataset_name="vector_result",
    output_image=r"D:/项目根目录/classification/classify_result.png",
)
if ok:
    print("专题图生成成功")
else:
    print("专题图生成失败")

示例2：自定义输出尺寸
--------------------------------------------------------------------------------
ok = generate_thematic_map(
    udbx_path=r"D:/result.udbx",
    dataset_name="change_polygons",
    output_image=r"D:/change_map.png",
    width=1920,
    height=1080,
)

示例3：在后台线程中调用（PyQt / tkinter）
--------------------------------------------------------------------------------
import threading

def generate_map_thread(udbx_path, dataset_name, output_image):
    from mapper import generate_thematic_map
    ok = generate_thematic_map(udbx_path, dataset_name, output_image)
    if ok:
        print("专题图生成完成")
    else:
        print("专题图生成失败")

t = threading.Thread(
    target=generate_map_thread,
    args=(udbx_path, dataset_name, output_image),
    daemon=True,
)
t.start()


五、核心依赖
================================================================================

依赖名称       用途
--------------------------------------------------------------------------------
iobjectspy      打开 UDBX 数据源，读取矢量数据集，渲染地图底图
PIL / Pillow    在底图上叠加绘制图例、比例尺、指北针、边框

注意事项：
- 本模块依赖 SuperMap iObjects Java 组件
- 运行前需确保 JAVA_HOME 和 iObjects Java Bin 路径已正确配置
- 配置通过 config.json 或环境变量完成


六、输出图片包含的元素
================================================================================

元素名称      位置        说明
--------------------------------------------------------------------------------
底图          全图        SuperMap 渲染的矢量地图
图例          右上角      显示各地物类型的颜色对应关系
比例尺        左下角      显示地图比例尺（单位：米）
指北针        左上角      N / S / E / W 方向指示
边框          边缘        黑色边框，使图片更规范


七、异常与注意事项
================================================================================

1. 数据源不存在
   - udbx_path 指向的文件不存在时，函数返回 False 并打印错误信息

2. 数据集不存在
   - 指定的 dataset_name 在数据源中不存在时，函数返回 False
   - 会打印数据集中所有可用数据集名称供参考

3. 字体缺失
   - 如果系统没有 simhei.ttf（黑体），图例和文字会使用默认字体
   - 可能显示为方框，建议确保系统字体目录存在黑体字体

4. 投影缺失
   - 如果数据源没有投影信息，地图仍会生成
   - 但比例尺可能不准确

5. 大图导出
   - 图片尺寸过大（如 4K 以上）可能导致内存不足
   - 建议保持默认 1200×900 或合理范围

6. 临时文件
   - 生成过程中会创建临时底图文件（_temp.png）
   - 函数结束时会自动删除


八、与主程序的集成方式
================================================================================

在 change_detection_ui.py 中已集成，调用路径如下：

用户点击「生成专题图」按钮
        ↓
_run_thematic_map_thread()  （后台线程）
        ↓
尝试多个数据集名称：
  - 用户指定的 dataset_name
  - "vector_result"       （地物分类输出）
  - "change_polygons"     （变化检测输出）
  - "binclassify_result"  （二分类输出）
  - "objdetect_result"    （目标检测输出）
        ↓
generate_thematic_map()   （核心函数）
        ↓
输出 PNG 图片
