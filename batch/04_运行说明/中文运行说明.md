# 李昌辉模块接口运行说明（V1.1 免 ArtifactTool 版）

## 1. 版本结论

V1.1 已取消对 Codex artifact-tool 及 Node.js 的运行时依赖，统计 Excel、4 张图表和 Word 报告全部由普通 Python 本地库生成。Microsoft Word 只用于可选 PDF 转换。

四个公开函数保持不变：

```python
run_batch_detection(...)
generate_statistics(...)
generate_report(...)
run_full_pipeline(...)
```

完整函数签名见 `02_接口说明/李昌辉模块接口说明.docx` 和 `05_测试与校验/对外接口契约.json`。

## 2. 安装依赖

在交接包根目录执行：

```powershell
python -m pip install -r requirements.txt
```

详细说明见 `04_运行说明/依赖安装说明.md`。

## 3. 目录引用

将 `01_源代码` 加入项目的 Python 搜索路径，或把其中必要源文件复制到主项目模块目录：

```python
from li_batch_api import (
    run_batch_detection,
    generate_statistics,
    generate_report,
    run_full_pipeline,
)
```

接口文件不会写死 F 盘、用户目录或内部运行时路径。输入、配置和输出目录均由调用方传入。

## 4. 统计调用示例

```python
from li_batch_api import generate_statistics

result = generate_statistics(
    status_table_path=r"D:\runs\batch_status.csv",
    output_dir=r"D:\runs\statistics",
    result_root=r"D:\runs\results",
)

print(result["excel_path"])
print(result["detail_csv_path"])
```

统计阶段使用 `rasterio` 读取成功或跳过任务对应的有效 TIFF，再由 `openpyxl` 生成 Excel。

## 5. 报告调用示例

```python
from li_batch_api import generate_report

result = generate_report(
    excel_path=r"D:\runs\statistics\批量变化检测统计汇总.xlsx",
    stats_csv_path=r"D:\runs\statistics\批量变化检测统计明细.csv",
    output_dir=r"D:\runs\report",
    report_title="徐州采煤塌陷区变化检测统计报告",
)

print(result["charts_dir"])
print(result["word_path"])
print(result["pdf_path"])
print(result["pdf_generated"])
print(result["warnings"])
```

报告成功至少表示：4 张图表与 Word 已生成。没有 Microsoft Word 或 `pywin32` 时，PDF 为空，但不会使报告阶段失败。

## 6. PyQt 工作线程注意事项

- `run_batch_detection`、`generate_statistics`、`generate_report` 和 `run_full_pipeline` 均可能耗时，必须放入 `QThread` 或线程池。
- `progress_callback` 只接收普通字典。推荐传入 PyQt 信号的 `emit` 方法。
- 后台函数不会创建窗口，也不会直接操作 UI 控件。
- 主线程槽函数收到进度信号后，再更新进度条和状态文本。

```python
result = run_full_pipeline(
    task_list_path=r"D:\project\tasks.csv",
    config_path=r"D:\project\batch_config.json",
    output_dir=r"D:\runs\pipeline",
    progress_callback=self.progress.emit,
    report_title="徐州采煤塌陷区变化检测统计报告",
    real_mode=True,
)
```

## 7. V1.0 参数兼容

以下参数仍保留在函数签名中，但 V1.1 不再使用：

- `node_executable`
- `node_modules_dir`
- `orchestrator_python`
- `project_python`
- `poppler_path`

旧调用代码即使继续传入这些参数也不会破坏运行；新代码请直接省略。

## 8. 输出与状态

- `success`：该阶段的必需输出是否成功。
- `failed`：单项检测或统计失败；批量模块仍继续处理其他任务。
- `skipped`：任务禁用、已有有效结果或断点续跑时跳过。
- `pdf_generated=False`：只表示可选 PDF 未生成，不代表图表或 Word 失败。
- 输出目录始终由调用方指定。

## 9. 未包含内容

交接包不包含 GPU/iObjectsPy 环境、模型、原始影像、大型 TIFF、许可文件、归档包、Node.js、npm、node_modules、缓存或无关日志。
