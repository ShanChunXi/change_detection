# 李昌辉模块 V1.1 依赖安装说明

## 一、普通 Windows 电脑安装

建议使用 Python 3.10 或更高版本。在交接包根目录打开 PowerShell 或命令提示符，执行：

```powershell
python -m pip install -r requirements.txt
```

如果项目使用虚拟环境，请先激活虚拟环境，再执行同一命令。

## 二、依赖用途

- `numpy`、`rasterio`：读取变化检测 TIFF，并完成像元数量、变化比例和面积统计。
- `openpyxl`：生成统计 Excel，不需要外部工作簿构建器。
- `matplotlib`、`Pillow`：生成并检查 4 张 PNG 图表。
- `python-docx`：生成 Word 报告。
- `pywin32`：在 Windows 已安装 Microsoft Word 时，将 DOCX 可选转换为 PDF。

## 三、变化检测环境

GPU、iObjectsPy、模型资源和许可属于“变化检测”阶段，未包含在本轻量交接包中。只有执行真实批量推理时才需要按项目原部署方案准备这些资源。

## 四、PDF 是可选输出

Word 报告始终由 `python-docx` 生成。若本机安装 Microsoft Word 且 `pywin32` 可用，接口会继续生成 PDF；否则：

- `generate_report` 仍返回 `success=True`；
- `pdf_path=None`；
- `pdf_generated=False`；
- 原因写入 `warnings`。

## 五、V1.1 可移植性说明

V1.1 已取消对 Codex artifact-tool 及 Node.js 的运行时依赖，报告生成采用 Python 本地库实现。Node.js、npm 和任何内部运行时目录均不再需要，也不应复制到项目中。

为兼容组长已经准备好的 V1.0 调用代码，`node_executable`、`node_modules_dir`、`orchestrator_python`、`project_python` 和 `poppler_path` 参数仍保留，但 V1.1 会忽略这些旧参数。
