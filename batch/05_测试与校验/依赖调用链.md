# 依赖调用链

## V1.0 原始问题

`li_batch_api.generate_statistics`
→ `_ensure_node_modules_link`
→ 子进程执行 `result_statistics.py`
→ `run_workbook_builder`
→ Node.js 执行 `result_statistics_workbook.mjs`
→ `import { FileBlob, SpreadsheetFile, Workbook } from "@oai/artifact-tool"`

`generate_report` 本身不直接导入该包；但 `run_full_pipeline` 在统计阶段就会进入上述链路，因而无法继续生成报告。

## V1.1 当前调用链

- Excel：`generate_statistics` → `result_statistics.py` → `build_workbook_openpyxl` → `openpyxl` → XLSX。
- 图表：`generate_report` → `build_charts_internal` → `matplotlib` → 4 张 PNG。
- Word：`generate_report` → `build_docx` → `python-docx` → DOCX。
- PDF（可选）：`generate_report` → `convert_word_to_pdf_optional` → `win32com.client` + Microsoft Word → PDF。

V1.1 的必需运行链不再调用 Node.js、npm、Codex 内部运行时或任何 JavaScript 工作簿生成器。
