# 通用变化检测模块 — 模块说明

**第24届 SuperMap 杯高校 GIS 大赛 开发组 · 张硕岐**

---

## 1. 模块功能

输入**两期遥感影像**（前期 T1 / 后期 T2），自动识别变化区域，输出**矢量 polygon**，并按类型分为四类：

| 变化类型 | 含义 |
|----------|------|
| 新增建筑 | T1 没有建筑，T2 出现建筑 |
| 消失地物 | T1 有建筑，T2 建筑消失 |
| 属性变更 | T1/T2 都有建筑但位于变化区域（改建/扩建） |
| 其他变化 | 非建筑类地表变化（道路、水体、植被等） |

同时提供**文件夹级别**的批量处理能力：自动扫描配对影像 → 顺序推理 → 实时追踪状态 → 生成汇总报告。

---

## 2. 环境依赖

| 组件 | 说明 |
|------|------|
| SuperMap iObjects Python (GPU) | Python 环境，内含 `iobjectspy` 库 |
| SuperMap iObjects Java | JRE + Bin 目录 |
| ML 资源包 | 内含 `model/` 文件夹（预训练模型） |

路径配置保存在 `src/config.json`，换电脑只需改一次。

## 3. 三种使用方式

### 3.1 交互菜单

```bash
python change_detection.py menu
```

菜单选项：

```
[1] 环境自检
[2] 查看模型列表
[3] 运行变化检测        基础版：推理 → 栅格输出
[4] 批量处理            CSV 文件批量
[5] 查看帮助
[6] 配置向导
[7] 图形界面
[8] 增强检测 (+矢量)    推理 → 矢量 → 变化分类  ← 推荐
[9] 文件夹批量           自动配对 → 顺序处理 → 汇总报告
[0] 退出
```

### 3.2 命令行

```bash
# 基础版：仅输出栅格
python change_detection.py run -b "2020.tif" -a "2024.tif" -o "result.udbx"

# 增强版：矢量输出 + 变化分类（推荐）
python change_detection.py run-vec -b "2020.tif" -a "2024.tif" -o "result.udbx"

# 增强版：仅矢量、不分类（更快）
python change_detection.py run-vec -b "2020.tif" -a "2024.tif" -o "result.udbx" --no-classify

# 增强版：过滤小于 50m² 的碎斑
python change_detection.py run-vec -b "2020.tif" -a "2024.tif" -o "result.udbx" --min-area 50

# 文件夹批量：自动配对 + 顺序处理
python change_detection.py batch-folder --folder "D:/data/xuzhou" --mode subdirs
```

### 3.3 图形界面

```bash
python change_detection.py ui
```

四种模式切换：单次检测 / 增强检测 / 批量CSV / 文件夹批量。

## 4. Python API

> 供贾思雨（专题图）、李昌辉（批量处理）在代码中直接调用。

### 4.1 `run_enhanced_inference()` — 增强版推理（推荐）

```python
from change_detection import run_enhanced_inference

ok, result = run_enhanced_inference(
    before_path="D:/data/2020.tif",     # 前期影像 (T1)
    after_path="D:/data/2024.tif",      # 后期影像 (T2)
    out_path="D:/result/change.udbx",    # 输出 UDBX 路径
    model_key="building",               # 模型（通常用 building）
    gpu=0,                              # GPU 编号，-1 用 CPU
    classify=True,                      # 是否分类（True=慢但详细）
    min_change_area=0,                  # 最小变化面积 (m²)，0=不过滤
    smooth=True,                        # 边界平滑
    batch_size=1,                       # 推理批大小
    out_format="udbx",                   # udbx 或 tif
)
```

**参数表**：

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `before_path` | str | 必填 | 前期影像路径，支持 .tif/.tiff/.img |
| `after_path` | str | 必填 | 后期影像路径 |
| `out_path` | str | 必填 | 输出文件路径（.udbx） |
| `model_key` | str | `"building"` | 模型：building / building-seg / landcover |
| `gpu` | int | `0` | GPU 编号，`-1` 用 CPU |
| `classify` | bool | `True` | 启用变化分类（额外运行 2 次 building-seg） |
| `min_change_area` | float | `0` | 最小变化面积 (m²)，小于此值过滤掉 |
| `smooth` | bool | `True` | 是否平滑矢量边界 |
| `batch_size` | int | `1` | 推理批大小 |
| `out_format` | str | `"udbx"` | 输出格式：udbx / tif |

**返回值 `result` 字典**：

```python
{
    "success": True,                      # 是否成功
    "before": "D:/data/2020.tif",         # 输入 T1
    "after": "D:/data/2024.tif",          # 输入 T2
    "output": "D:/result/change.udbx",     # 输出文件路径
    "model": "building",                  # 使用的模型
    "classification_enabled": True,       # 是否启用了分类
    "duration_s": 45.2,                   # 耗时（秒）

    "vector_stats": {                     # 矢量统计
        "polygon_count": 156,             # 变化 polygon 数量
        "total_area_m2": 12345.6,         # 总面积 (m²)
        "min_area_m2": 10.2,
        "max_area_m2": 890.1,
    },

    "change_stats": {                     # 变化分类（仅 classify=True）
        "classification": {
            "新增建筑": 45,
            "消失地物": 23,
            "属性变更": 12,
            "其他变化": 76,
            "总计": 156,
        },
    },

    "error": None,                        # 失败原因（成功时为 None）
}
```

**输出文件**：UDBX 数据源，内含 `change_polygons` 矢量数据集，每个 polygon 含以下属性：

| 字段 | 类型 | 说明 |
|------|------|------|
| `change_type` | 文本 | 新增建筑 / 消失地物 / 属性变更 / 其他变化 |
| `area_m2` | 浮点 | polygon 面积 (m²) |
| `SmID` | 整数 | 系统自动生成的要素 ID |

### 4.2 `run_single_inference()` — 基础版推理

```python
from change_detection import run_single_inference

ok = run_single_inference(
    before_path="D:/data/2020.tif",
    after_path="D:/data/2024.tif",
    out_path="D:/result/change.udbx",
    model_key="building",
    gpu=0,
    out_format="udbx",
)
# 返回 bool，True=成功
```

仅输出**栅格掩膜**，不做矢量转换和分类。适合只需要二值变化图的场景。

### 4.3 `run_folder_batch()` — 文件夹批量

```python
from change_detection import run_folder_batch

ok = run_folder_batch(
    folder="D:/data/xuzhou",        # 数据根目录
    mode="subdirs",                 # 配对模式
    model_key="building",
    gpu=0,
    classify=True,
    output_dir="D:/results",        # 统一输出目录（可选）
)
# 返回 bool，True=全部成功
```

**文件夹结构（subdirs 模式）**：

```
D:/data/xuzhou/
├── before/
│   ├── area1_2020.tif
│   ├── area2_2020.tif
│   └── area3_2020.tif
└── after/
    ├── area1_2024.tif
    ├── area2_2024.tif
    └── area3_2024.tif
```

按文件名自动配对：`area1_2020.tif` ↔ `area1_2024.tif`。

处理完成后生成：
- `batch_status_YYYYMMDD_HHMMSS.json` — 每个任务的状态、耗时、统计
- 每对影像对应的 `*_change.udbx` 矢量结果

### 4.4 `FolderBatchProcessor` 类 — 高级批量控制

```python
from change_detection import FolderBatchProcessor

bp = FolderBatchProcessor(
    model_key="building",
    gpu=0,
    output_dir="D:/results",
    classify=True,
    min_change_area=50,
)

# 扫描配对
bp.scan_pairs("D:/data/xuzhou", mode="subdirs")

# 顺序处理（可传入进度回调）
bp.process_all(progress_callback=lambda i, task: print(f"{i}: {task['status']}"))

# 获取失败任务
for task in bp.get_failed_tasks():
    print(f"失败: {task['name']} — {task['error']}")

# 导出报告
bp.save_report("D:/results/report.json")
```

## 5. 配置文件

`src/config.json` 结构：

```json
{
    "java_home":    "F:/.../jre1.8_x64",
    "iobjects_bin": "F:/.../Bin",
    "resources_ml": "F:/.../resources_ml",
    "python_path":  "F:/.../python.exe",
    "last_params": {
        "before": "上次的前期影像路径",
        "after":  "上次的后期影像路径",
        "out":    "上次的输出路径",
        "model":  "building",
        "gpu":    0,
        "out_format": "udbx",
        "classify": true,
        "min_change_area": 0
    }
}
```

`last_params` 自动记忆，下次打开自动回填。`load_config()` / `save_config()` 提供读写接口。

## 7. 可用模型

| Key | 名称 | 输入 | 用途 |
|-----|------|------|------|
| `building` | SiamSFNet | 两期影像 | 建筑物变化检测（本模块主要使用） |
| `building-seg` | SegFormer | 单张影像 | 建筑物分割（变化分类时内部调用） |
| `landcover` | 多类别 | 单张影像 | 地物分类（李晨曦模块使用） |

## 8. 常见问题

**Q: 启动很慢？**
SuperMap 每次初始化需要复制 34 个 JAR 文件，约 60 秒。等一会就好。

**Q: 输出全黑？**
变化检测输出是 0/1 二值掩膜，在普通图片查看器中 1 也接近黑色。用 QGIS 或 SuperMap iDesktop 打开。

**Q: 为什么分了类却全是"未分类"？**
变化分类需要额外运行 building-seg 模型。如果 building-seg 模型文件缺失或 API 版本不兼容，分类步骤会跳过，所有变化标记为"未分类"。变化检测结果本身不受影响。

**Q: 显存不足？**
GPU 选 `-1` 改用 CPU，或减小 `batch_size`。

**Q: 如何给贾思雨提供数据？**
把 `run_enhanced_inference` 输出的 `.udbx` 文件给她。她用 SuperMap 打开 `change_polygons` 数据集，按 `change_type` 字段分层设色即可。
