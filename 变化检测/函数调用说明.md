## 模块概述

输入两期遥感影像（前期 T1 / 后期 T2），调用 SuperMap 深度学习模型识别变化区域，支持输出栅格掩膜或矢量 polygon，可选自动将变化分为四类（新增建筑 / 消失地物 / 属性变更 / 其他变化），并提供文件夹级别的批量处理能力。

---

## 核心函数

### 1. `run_single_inference()` — 基础版变化检测

对一对影像做变化检测推理，输出栅格结果。

```python
from change_detection import run_single_inference

ok: bool = run_single_inference(
    before_path: str,       # 前期影像路径 (T1)，.tif / .tiff / .img
    after_path: str,        # 后期影像路径 (T2)
    out_path: str,          # 输出文件路径，.udbx 或 .tif
    model_key: str = "building",   # 模型: building / building-seg / landcover
    gpu: int = 0,           # GPU 编号，-1 表示 CPU
    batch_size: int = 1,    # 推理批大小
    offset: int = None,     # 滑动窗口偏移，None 使用模型默认值
    result_type: str = "grid",      # 结果类型: grid / region
    out_dataset_name: str = "predict_change",  # 输出数据集名
    out_format: str = "udbx",        # 输出格式: udbx / tif
) -> bool   # True=成功, False=失败
```

**输出**：UDBX 数据源（含 `predict_change` 栅格数据集）或 GeoTIFF 文件。

---

### 2. `run_enhanced_inference()` — 增强版变化检测 ⭐

完整流程：推理 → 栅格转矢量 → 变化分类。输出带 `change_type` 属性的矢量 polygon。

```python
from change_detection import run_enhanced_inference

ok: bool, result: dict = run_enhanced_inference(
    before_path: str,       # 前期影像路径 (T1)
    after_path: str,        # 后期影像路径 (T2)
    out_path: str,          # 输出文件路径 (.udbx)
    model_key: str = "building",   # 模型: building / building-seg / landcover
    gpu: int = 0,           # GPU 编号，-1=CPU
    classify: bool = True,  # 是否启用变化类型分类（会额外运行2次 building-seg）
    min_change_area: float = 0,     # 最小变化面积过滤 (m²)，0=不过滤
    smooth: bool = True,    # 矢量边界平滑
    batch_size: int = 1,    # 推理批大小
    offset: int = None,     # 滑动窗口偏移
    out_format: str = "udbx",        # 输出格式: udbx / tif
) -> Tuple[bool, dict]
```

**返回值 `result` 字典**：

```python
{
    "success": True,                    # 是否成功
    "before": "D:/data/2020.tif",      # 输入的前期影像
    "after": "D:/data/2024.tif",       # 输入的后期影像
    "output": "D:/result/change.udbx",  # 输出文件路径
    "model": "building",               # 使用的模型
    "classification_enabled": True,    # 是否启用了分类
    "duration_s": 45.2,                # 耗时 (秒)

    "vector_stats": {                  # 矢量转换统计
        "polygon_count": 156,          # 变化 polygon 数量
        "total_area_m2": 12345.6,      # 变化总面积 (m²)
        "min_area_m2": 10.2,           # 最小变化面积
        "max_area_m2": 890.1,          # 最大变化面积
    },

    "change_stats": {                  # 变化分类统计（classify=True 时）
        "classification": {
            "新增建筑": 45,
            "消失地物": 23,
            "属性变更": 12,
            "其他变化": 76,
            "总计": 156,
        },
    },

    "error": None,                     # 失败时的错误信息
}
```

**输出文件**：UDBX 数据源，内含 `change_polygons` 矢量数据集，每个 polygon 字段：
| 字段 | 类型 | 说明 |
|------|------|------|
| `change_type` | 文本 | 新增建筑 / 消失地物 / 属性变更 / 其他变化 / 未分类 |
| `area_m2` | 数值 | polygon 面积 (m²) |

### 3. `run_batch_inference()` — CSV 批量处理

从 CSV 文件读取任务列表，逐对执行基础版推理。

```python
from change_detection import run_batch_inference

ok: bool = run_batch_inference(
    csv_path: str,          # CSV 文件路径
    model_key: str = "building",
    gpu: int = 0,
    batch_size: int = 1,
    offset: int = None,
    result_type: str = "grid",
    out_format: str = "udbx",
) -> bool   # True=全部成功, False=有失败
```

**CSV 格式**（无表头）：
```
前期影像路径,后期影像路径,输出路径[,数据集名]
```
示例：
```
D:/data/t1_2020.tif,D:/data/t1_2024.tif,D:/result/t1.udbx
D:/data/t2_2020.tif,D:/data/t2_2024.tif,D:/result/t2.udbx,my_dataset
```

### 4. `run_folder_batch()` — 文件夹批量处理 ⭐

自动扫描文件夹配对影像，顺序逐对执行增强版推理，生成状态文件和汇总报告。

```python
from change_detection import run_folder_batch

ok: bool = run_folder_batch(
    folder: str,            # 数据文件夹路径
    mode: str = "subdirs",  # 配对模式: subdirs / pattern / pairs_file
    model_key: str = "building",
    gpu: int = 0,
    classify: bool = True,  # 是否启用变化分类
    min_change_area: float = 0,
    out_format: str = "udbx",
    output_dir: str = None, # 统一输出目录，None=各影像所在目录
    pattern: Tuple[str, str] = None,  # mode="pattern" 时的前后缀
) -> bool   # True=全部成功, False=有失败
```

**三种配对模式**：

| 模式 | 目录结构 | 说明 |
|------|----------|------|
| `subdirs` | `folder/before/*.tif` + `folder/after/*.tif` | 按文件名匹配 |
| `pattern` | `folder/*_T1.tif` + `folder/*_T2.tif` | 按前后缀配对，可通过 `pattern=("_T1", "_T2")` 指定 |
| `pairs_file` | `folder/pairs.json` 或 `folder/pairs.csv` | 显式列表 |

**输出文件**：
- 每对影像一个 `*_change.udbx`（矢量结果）
- `batch_status_YYYYMMDD_HHMMSS.json` — 实时状态追踪
- `batch_report_YYYYMMDD_HHMMSS.json` — 汇总报告

---

### 5. `FolderBatchProcessor` 类 — 批量处理器（高级）

需要更细粒度控制时使用。

```python
from change_detection import FolderBatchProcessor

bp = FolderBatchProcessor(
    model_key: str = "building",
    gpu: int = 0,
    output_dir: str = None,
    classify: bool = True,
    out_format: str = "udbx",
    batch_size: int = 1,
    offset: int = None,
    min_change_area: float = 0,
    smooth: bool = True,
)

# 扫描配对
count: int = bp.scan_pairs(folder, mode="subdirs")

# 顺序处理
all_ok: bool = bp.process_all(progress_callback=None)

# 获取失败任务
failed: list = bp.get_failed_tasks()

# 导出报告
report_path: str = bp.save_report("report.json")
```

## 辅助函数

| 函数 | 说明 | 返回值 |
|------|------|--------|
| `list_models()` | 打印所有可用模型信息 | 无 |
| `get_model_info(key)` | 获取模型配置字典 | `dict`，含 name/path/offset |
| `load_config()` | 加载 config.json | `dict` |
| `save_config(cfg)` | 保存 config.json | `bool` |
| `run_self_check()` | 环境自检 (Python/Java/CUDA/模型) | `bool` |
| `run_setup_wizard()` | 交互式配置向导 | 无 |

---

## 可用模型

| Key | 名称 | 输入 | 用途 |
|-----|------|------|------|
| `building` | SiamSFNet 建筑物变化检测 | 两期影像 | 对比前后影像，检测建筑物变化 |
| `building-seg` | SegFormer 建筑物分割 | 单张影像 | 提取影像中的建筑物 |
| `landcover` | 多类别地物分类 | 单张影像 | 土地利用/覆盖分类 |

## 快速速查

```bash
# 基础版
python change_detection.py run -b 2020.tif -a 2024.tif -o result.udbx

# 增强版（矢量+分类）
python change_detection.py run-vec -b 2020.tif -a 2024.tif -o result.udbx

# 增强版（仅矢量，不分类）
python change_detection.py run-vec -b 2020.tif -a 2024.tif -o result.udbx --no-classify

# 文件夹批量
python change_detection.py batch-folder --folder D:/data --mode subdirs

# 交互菜单
python change_detection.py menu
```
